# Archived build specs

These `Phase-*.md` files are the **historical implementation specs** written while building
Roaster. They are **frozen** — they describe the design *at the time each phase was built*
and are not kept in sync with the code. Several are already out of date (e.g. the reviewer
predates the multi-agent fan-out).

**For current-state documentation, use:**
- [BACKEND.md](../../BACKEND.md) — backend data flow, endpoints, reviewer, config
- [FRONTEND.md](../../FRONTEND.md) — Blazor WASM structure
- [RUNNING.md](../../RUNNING.md) — setup, run, configuration

They are kept for rationale/history only. Active forward plans live one level up in
`Documentations/Plans/`.
